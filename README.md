# -yap-messenger
Yap. Nobody gets to silence you. A free, open-source, decentralised messenger built for communication without internet access.

The Android 0.2 debug build adds experimental paired encryption, durable queues,
foreground local mesh and a private internet relay client. Read the
[debug release guide](docs/debug-release-0.2.md) and
[build instructions](android/README.md). Physical multi-phone mesh testing and an
independent security audit remain pending; this is development software.
